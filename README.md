# 🎭 Шуточный «винлокер» (Prank Screen Locker)

> ⚠️ Это полноэкранная имитация блокировки, а не безобидная заставка: программа перехватывает некоторые системные сочетания клавиш. Запускай её только на своём компьютере или в тестовой виртуальной машине и только с согласия пользователя. Не запускай от имени администратора и не добавляй в автозагрузку.

## Что делает программа

`Locker.py` показывает полноэкранную анимацию с фальшивыми сообщениями о шифровании и перезагрузке, проигрывает звуки и временно блокирует часть клавиш. Она **не шифрует и не удаляет файлы**, не запускает показанные на экране команды и не отправляет данные в сеть.

## Как запустить

1. Установи Python 3 для Windows.
2. Открой терминал в папке проекта.
3. Установи зависимость:

   ```bash
   py -m pip install keyboard
   ```

4. Запусти скрипт:

   ```bash
   py Locker.py
   ```

Не запускай его с правами администратора. Перед тестированием сохрани работу и закрой важные приложения.

## Как выйти

**Пароль выхода: `123`.** Когда появится поле ввода, введи `123` и нажми Enter. Программа покажет сообщение, что это была шутка, разблокирует перехваченные клавиши и закроется.

Если окно не реагирует, попробуй нажать `Ctrl+C` в терминале, из которого запущен скрипт. Если это не помогло, нажми `Ctrl+Alt+Delete`, открой Диспетчер задач и заверши процесс Python (`python.exe` или `pythonw.exe`). Не используй принудительное выключение компьютера, пока доступны эти способы.

## Состав проекта

- `Locker.py` — исходный код программы;
- `voice.b64` — данные звукового эффекта, используемые скриптом;
- `sound1.b64` — присутствует в репозитории, но текущий код ищет файл `sound.b64`, поэтому этот файл сам по себе не будет использован как основной звук.

## Ограничения и предупреждение

Это демонстрационный проект, не предназначенный для реальной защиты или блокировки компьютера. Не запускай его на чужом устройстве без явного согласия владельца. Если публикуешь или передаёшь программу, сообщай пароль выхода заранее и оставляй рядом эту инструкцию.
